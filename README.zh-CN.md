# PhD Radar

[English](README.md) | **简体中文**

PhD Radar 是一个面向 Codex 的博士机会搜索技能，用于发现、核验、筛选、评分、排序并展示有薪或全额资助的博士机会。它把自然语言需求转化为有边界的检索任务，在官方页面核验候选线索，并输出可追溯的候选清单，而不是把搜索摘要直接当作真实职位。

## 能做什么

- 保存并复用搜索配置，包括地区、主题、方法、资助规则、申请资格和排除条件。
- 同时搜索公开招聘的博士职位，以及经过核验的带资助博士项目申请通道。
- 结合结构化来源类别与针对不同地区的开放网络检索。
- 返回大学、研究机构、雇主、项目或官方申请页面核验信息。
- 可按配置执行 QS 学校/学科门槛和研究团队证据检查。
- 对已核验结果按 0.0-10.0 分评分，并使用确定性规则排序。
- 汇报搜索覆盖与排除原因，并可生成独立的 HTML 卡片仪表盘。

## 安装

克隆仓库，然后将技能复制到 Codex 的技能目录：

```powershell
git clone https://github.com/aaswads/phd-radar.git
Copy-Item -Recurse .\phd-radar\skill-src\phd-radar "$HOME\.codex\skills\phd-radar"
```

重启 Codex 或新建一个任务，让 Codex 重新发现技能。

## 如何使用

直接使用自然语言提出需求即可。明确说出技能名称是最直接的触发方式：

> 使用 PhD Radar，帮我寻找荷兰、德国和北欧地区与 Human-AI Interaction 相关的有薪博士职位。

常用的后续指令包括：

- `刷新我的 PhD Radar 搜索结果。`
- `这次只查瑞士，不修改默认配置。`
- `以后把 QS 总榜门槛改成前 200。`
- `解释为什么第 3 个结果排在第 4 个前面。`
- `生成并打开卡片式仪表盘。`
- `把这个公开职位网站加入搜索源：<URL>。`

PhD Radar 会区分“以后、默认、保存”等永久修改表达与“这次、本轮、临时”等一次性表达。永久修改会先预览再保存；临时覆盖不会改变个人配置。

## 第一次配置

首次运行时，PhD Radar 会检查是否存在已保存的 `default` 配置。如果不存在，它会提供一段可复制填写的配置表。其中两项必填：

- **目标地区**，例如荷兰、德国、北欧或英国。
- **研究主题**，例如 Human-AI Interaction、AI Agent Evaluation 或 Human Factors。

还可以填写：

- QS 官方学科名称；
- 学历和专业背景；
- 研究方法与技能；
- 应用领域；
- 语言与资格限制；
- 最早入学时间；
- 明确排除项；
- 个人 CV，但仍需明确目标地区和研究主题。

首次配置示例：

```text
目标地区：荷兰、德国、丹麦、瑞典
研究主题：Human-AI Interaction、LLM Agent Evaluation
QS 目标学科：Computer Science and Information Systems、Psychology
申请背景：Human Factors 硕士，预计 2027 年 6 月毕业
方法与技能：用户实验、统计、Python、混合研究方法
应用领域：航空与安全关键系统
语言与资格限制：只考虑英语岗位
最早入学时间：2027 年 9 月
必须排除：需要自费的项目
```

填写并回复这段配置即代表确认第一次保存。技能会将内容与可执行默认值合并，写入配置文件，再重新读取并展示摘要。默认保存位置是：

```text
~/.codex/phd-radar/profile.json
```

可以通过 `PHD_RADAR_STATE_DIR` 更改状态目录。个人配置和生成的搜索结果不会进入本开源仓库。

### 默认配置

如果用户没有修改，首次配置采用以下默认值：

- 机会类型：PhD、doctoral researcher、doctoral candidate；
- 资助要求：只考虑有薪或全额资助；
- 截止日期：排除已过期机会；截止日期未知的机会不进入正式推荐；
- 申请通道：公开职位与经过核验的带资助博士项目通道；
- 检索方式：来源类别加地区化开放网络检索，之后返回官方页面核验；
- QS 总榜门槛：前 300，包含第 300 名；
- QS 学科门槛：前 100，包含第 100 名；前 50 优先；配置的任一学科通过即可；
- 未上榜学校：进入人工复核，而不是自动接受；
- 研究团队审查：近五年研究连续性、ERC/MSCA 证据、博士培养与去向、外部合作；
- 正式结果目标：20 个；
- 宽搜候选池：约为正式结果目标的 3 倍，上限 60 个；
- 输出语言：中文。

这些只是起始默认值，不代表对用户背景的推断，均可通过对话修改。

## 搜索源与核验方式

开源技能包**不包含隐藏的固定网站数据库，也不会宣称穷尽整个互联网**。它针对每个目标地区，从以下来源类别建立有边界的检索计划：

1. **职位来源：**大学与研究机构的公开招聘门户、EURAXESS 或地区同类平台，以及定向职位检索。
2. **官方学校和项目页面：**研究生院、博士项目、院系、研究中心和资助页面。
3. **导师与实验室页面：**官方教师和实验室名录，用于发现研究方向与招生信号。
4. **项目与资助方来源：**ERC、MSCA、CORDIS、国家资助机构、联合项目和项目官网。
5. **仅用于发现线索的来源：**搜索引擎、聚合站、Scholar、dblp、OpenReview、ORCID、DOI/出版商记录和领域目录。

第 5 类来源可以帮助发现线索，但不能单独证明某个有资助职位真实存在。每条有价值的线索都必须返回最具体的官方职位页、项目页、学校/雇主页或指定申请页。技能会逐字段核验职位是否存在、学校、地区、类型、开放状态、截止日期、资助或薪资、申请资格、工作语言、PI/联系人和申请链接。

每个来源或查询都会得到可见状态，例如 `success`、`zero_results`、`blocked`、`failed`、`skipped` 或 `budget_limited`。失败或空结果会作为覆盖限制报告，不会被悄悄解释成“已经搜全”。

## 筛选、评分与排序

只有完成官方证据链核验并去重的机会，才进入正式评分。

### 评分维度

每个候选机会包含四个 0.0-10.0 原始分：

- **研究匹配度：**研究主题、研究问题、方法、应用领域和长期方向的匹配程度。
- **申请资格：**学历、专业、必需技能、申请人资格和语言匹配度。
- **资助可信度：**薪资、合同、奖学金、学费和资助证据的强度与完整性。
- **综合匹配度：**按当前配置计算的加权推荐分。

本技能没有设置一个不公开的统一权重公式。综合分的权重属于当前生效配置；当权重影响解释时，应随结果披露。展示分数采用常规四舍五入保留一位小数，但排序保留未舍入原始值。

### 硬门槛

高分不能覆盖硬性冲突。截止日期已过、资助不符合要求、明确不具备申请资格、无法满足必要语言要求，或未通过已配置的 QS 门槛，都会阻止正式推荐。未知信息保持为“未知”，不会被乐观加分。

默认等级划分为：

- **S：**综合、研究匹配和申请资格均至少 8.5，资助至少 8.0，且所有硬门槛通过。
- **A：**综合、研究匹配和申请资格均至少 7.5，资助已确认可接受，且没有淘汰性门槛。
- **B：**综合分 6.0-7.4，或存在有意义且可解释的主题/方法转向。
- **C：**核心匹配较弱、存在硬冲突、资助不可接受、职位已过期或申请价值较低。

等级只用于解释，最终顺序以数值排序为准。

### 确定性排序

结果依次按照以下规则排序：

1. 未舍入综合匹配分，从高到低；
2. 未舍入研究匹配分，从高到低；
3. 未舍入申请资格分，从高到低；
4. 未舍入资助可信度分，从高到低；
5. 已知且有效的截止日期，越早越靠前；未知日期排在最后；
6. 稳定机会 ID，按升序排列。

该顺序可通过 `scripts/rank_results.py` 复现，并在对话、JSON 数据包、电子表格和仪表盘中保持一致。

## 结果与仪表盘

PhD Radar 会先汇报实际搜索条件和覆盖情况，包括选中及失败的来源、Web 查询、原始线索、官方页面回查、重复项、排除项、已核验结果、资助确认、截止日期、QS 结果和未完成检查。随后展示带官方链接与申请链接的排序候选清单。主要结论会保留在对话中，因此仪表盘不是理解结果的必要条件。

用户要求后，技能可以生成独立、只读的 HTML 仪表盘：

```powershell
python .\skill-src\phd-radar\scripts\render_dashboard.py results.json `
  --output .\output\phd-radar-dashboard.html
```

仪表盘包含：

- 搜索摘要和覆盖指标；
- 文本、地区、最低分、QS 结果和实验室审查状态筛选；
- 按排名展示的卡片，包括标题、学校、地区、截止日期、资助、PI/联系人、推荐理由、风险提示和官方链接；
- 可展开的逐字段证据；
- 明确的链接缺失、证据未知、空结果和覆盖不完整状态；
- 无外部运行依赖的桌面与移动端布局。

Web 仪表盘有意只展示一个综合分，例如 `9.1 / 10`。研究匹配、申请资格、资助可信度和 S/A/B/C 等级仍保留在筛选与解释流程中，但不在卡片界面显示，以保持阅读和决策清晰。

## 使用边界与安全

PhD Radar 只搜索公开信息、核验证据并创建本地报告。它不会绕过登录、验证码、付费墙或访问限制，也不会代替用户提交申请。博士职位信息可能变化，申请前请始终以链接指向的官方申请页面为准。
